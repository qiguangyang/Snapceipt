# Snapceipt.cc — SEO + GEO Audit & Action Plan

_Date: 2026-07-04 · Scope: snapceipt.cc marketing site (static HTML on Cloudflare Workers, 9 SEO guides, home + pricing/privacy/terms/support)_

## 1. Executive summary

Technical fundamentals are strong: clean canonicals, correct `lang="en-AU"`, unique titles/descriptions, real 404s, guides carrying valid `Article` + `BreadcrumbList` JSON-LD. The damage is concentrated on the **home + 4 core pages**, which regressed in the marketing redesign: they point `og:image` at an SVG (blank social previews everywhere), use the small Twitter card, carry **zero structured data**, and lack a Smart App Banner. For an AU iOS-first app, the biggest levers are (a) making the home page a machine-readable entity (app/org/price/FAQ schema + `llms.txt`) so answer engines can state "Snapceipt is an AU receipt app, AUD 9.99/mo, by Techsider Pty Ltd," and (b) fixing social/app-banner meta to recover share CTR and install intent.

## 2. P0 — quick wins (high impact, low effort, low risk)

1. **Fix OG/Twitter + add Smart App Banner** on `public/index.html`, `pricing.html`, `privacy.html`, `support.html`, `terms.html`: swap `og:image` → real 1200×630 PNG (`/assets/og-default.png`), add `og:image:width/height/alt`, `og:site_name`, `og:locale=en_AU`, `twitter:card=summary_large_image` + `twitter:image`, and `<meta name="apple-itunes-app" content="app-id=6778894594">`.
2. **Smart App Banner + og:locale/site_name on guides** via `template.js` head (and `guides/index.html`).
3. **Home JSON-LD** — Organization + WebSite + SoftwareApplication `@graph` **plus** home `FAQPage` (5 Q&As from index.html FAQ) before `</head>`. `legalName: Techsider Pty Ltd`. No `aggregateRating`, no `SearchAction`.
4. **Create `public/llms.txt`** — summary + key facts + AUD pricing + guides + product pages.
5. **Open robots.txt to AI crawlers** — GPTBot / OAI-SearchBot / ClaudeBot / PerplexityBot / Google-Extended `Allow: /`, advertise sitemap + llms.txt.
6. **Sitemap `<lastmod>`** — `build.mjs` emit from `page.updated` per guide.
7. **Fix `/guides` slash mismatch** — sitemap loc + canonical + breadcrumb advertise `/guides` (307→`/guides/`). Use `/guides/` everywhere.
8. **Demote 3 decorative `<h1>`s** in `index.html` (phone-mockup `scr-h1` labels) → keep one true H1.
9. **Trim home meta description** (~153 chars).
10. **Add `public/_headers`** — long cache for `/assets/*` + fonts, short CSS, HTML `max-age=0`; HSTS + `X-Content-Type-Options: nosniff` + `Referrer-Policy`.
