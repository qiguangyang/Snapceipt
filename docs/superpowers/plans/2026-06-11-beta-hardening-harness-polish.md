# Beta-Hardening Harness + Polish Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build a deterministic screenshot-tour harness, then run a per-area rendered-pixel audit/fix loop across all 10 audit areas plus a cross-screen consistency pass, leaving every in-guardrail polish finding fixed (or deferred-logged) with the full iOS + backend suites green.

**Architecture:** Phase 0 extends the existing in-app DEBUG seeding seam (`AppLaunch.applySeedIfNeeded`) with a rich both-profiles fixture set selected by a new `-uiTestTour` launch arg (plus an empty `-uiTestTourEmpty`), adds a pinnable clock (`Epoch.override`) AND threads `Epoch.now()` into the view-layer "now" seams (Reports/Budgets/Alerts/WFH/Logbook FY + the two `RootView` window literals) so seeded data, timestamps, AND the month/week windows the screens actually render are all stable, and adds a `ScreenshotTourUITests` class (one method per audit area + three cross-cutting methods for empty/accent/large-type) plus `scripts/tour.sh` that boots the sim, pins the status bar, runs the tour with `-resultBundlePath`, and exports XCTAttachment PNGs via `xcrun xcresulttool export attachments` into `artifacts/tour/<run-id>/<area>/<screen>-<state>.png`. Phase 1 is a disciplined audit→adversarial-verify→fix→re-shoot→suite-green loop, one task per area, sequenced so shared design-token/primitive edits never collide.

**Tech Stack:** Swift / SwiftUI / SwiftData / XCTest (XCUITest) on iPhone 16 simulator (Xcode 26.5), XcodeGen project generation, `xcrun xcresulttool` (version 24757) attachment export, `xcrun simctl status_bar override`, bash.

```swift
/// Epoch-millisecond clock. All `createdAt`/`updatedAt`/`deletedAt` timestamps
/// (the LWW + cursor key) are integer ms in UTC.
enum Epoch {
    /// DEBUG-only pin for deterministic UI-test/tour runs. When non-nil, `nowMs()`
    /// and `now()` return this fixed instant instead of the wall clock. nil in
    /// Release (the property is compiled out).
    #if DEBUG
    static var override: Int?
    #endif

    /// Current time as integer epoch milliseconds (or the pinned override).
    static func nowMs() -> Int {
        #if DEBUG
        if let override { return override }
        #endif
        return Int((Date().timeIntervalSince1970 * 1000).rounded())
    }

    /// Current time as a `Date` (or the pinned override). Used by seeders.
    static func now() -> Date {
        Date(timeIntervalSince1970: Double(nowMs()) / 1000)
    }
}
```

```swift
import XCTest

/// Screenshot helper for `ScreenshotTourUITests`. `shoot(name:)` settles the UI,
/// captures the full app screen, and attaches it with `lifetime = .keepAlways`
/// and the screen name so `scripts/tour.sh` can export it via `xcresulttool`.
/// The attachment NAME is the `<screen>-<state>` token the script maps to a PNG.
extension XCTestCase {
    /// Settle, then attach a named full-app screenshot.
    /// - Parameter app: the launched application under test.
    /// - Parameter name: the `<screen>-<state>` token (e.g. `home-populated-business`).
    func shoot(_ app: XCUIApplication, _ name: String, settle: TimeInterval = 0.6) {
        // Let any in-flight enter/transition animation finish before capturing.
        // 0.6s comfortably exceeds the longest UI animation in the app
        // (ProgressBar .6s; most are <= .34s snap-curve).
        let deadline = Date().addingTimeInterval(settle)
        while Date() < deadline { _ = app.exists }   // spin without blocking the run loop

        let shot = app.screenshot()
        let att = XCTAttachment(screenshot: shot)
        att.name = name
        att.lifetime = .keepAlways
        add(att)
    }

    /// Wait for an element to exist (default 8s) and fail with a clear message if not.
    @discardableResult
    func require(_ element: XCUIElement, _ label: String, timeout: TimeInterval = 8) -> Bool {
        let ok = element.waitForExistence(timeout: timeout)
        XCTAssertTrue(ok, "tour: \(label) never appeared")
        return ok
    }
}
```
